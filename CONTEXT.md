# rcink glossary

- **Wedge** — chip parked in ROM download mode instead of running firmware or
  entering deep sleep.
- **Sleep proof** — USB port de-enumeration after a wake cycle; meter-free
  evidence of deep sleep.
- **`data_ts`** — page content-change time, carried forward while content is
  unchanged.
- **Wake cycle** — wake → sense → maybe fetch → render or skip → deep sleep.
